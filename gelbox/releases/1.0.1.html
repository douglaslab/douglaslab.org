Gelbox 1.0.1

October 11, 2026 · Build 20261011

Launch web app preview Download for Apple Silicon

What changed

  • DNA bands start flat at time zero. Curvature increases over the first ten simulated minutes.
  • Negative voltage reverses smiling bands into frowning bands.
  • The macOS app builds with current Cinder and includes its assets so it can run independently of the source checkout.
  • Loading another gel closes stale gel settings so buffer controls apply to the current document.
  • High-resolution controls and text are selected at display scales above 1×.

Web app preview

Gelbox now runs in the browser with WebGPU or WebGL2. The web version includes the curvature changes above. Work to verify complete native behavior and visual parity is ongoing.

macOS download

Version 1.0.1 is for Apple Silicon Macs. The build targets macOS 11 and later and was built on macOS 27.0.1. This refreshed build is prepared for local review; GUI smoke testing is pending. Copy Gelbox.app from the disk image into Applications.

This build is ad-hoc signed and has not been notarized by Apple. macOS may block the downloaded app on first launch. The web version requires no installation.

The original Intel download (1.0) remains available; it does not contain these fixes.
